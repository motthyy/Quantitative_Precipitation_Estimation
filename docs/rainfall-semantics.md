# 解析雨量の時間的意味

解析雨量は各表示時刻までの前1時間降水量である。

| 表示時刻 | 対象期間 |
|---|---|
| 12:00 | 11:00〜12:00 |
| 12:30 | 11:30〜12:30 |
| 13:00 | 12:00〜13:00 |
| 13:30 | 12:30〜13:30 |

30分更新値は30分間雨量ではない。累積では00分のフレームだけを用いる。3時間累積なら01:00、02:00、03:00の合計とする。01:30や02:30を混ぜない。

## 欠測

- NoDataは0 mmではない
- 必要な正時フレームがなければ累積は「欠測を含む」
- 時間補間は初期状態で行わない
- 0 mmは観測・解析結果としてのゼロであり、欠測と別

## 空間抽出

地点値はCOG数値格子のnearest cellを用いる。境界では西・北側から計算された一意のセルindexへfloorで割り当て、grid IDとgrid centerを返す。画像RGBは利用しない。

## JST/UTC

ファイル名のJMA配信時刻はUTC。Pythonでtimezone-aware UTCとして解読し、manifestとUIでは`Asia/Tokyo`へ変換する。2018-07-07 00:00 UTCは2018-07-07 09:00 JSTである。
