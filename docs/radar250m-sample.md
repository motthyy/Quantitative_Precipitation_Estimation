# 250mレーダー公式サンプル

## 出典

- 公開者：一般財団法人 気象業務支援センター（JMBSC）
- データ：気象庁 高解像度降水ナウキャスト、降水強度
- 公式一覧：https://www.jmbsc.or.jp/jp/online/c-onlineGsample.html
- 公式ZIP：https://www.jmbsc-west.jp/jp/online/online-sample/NOWC_GPV_Ggis0p25km/Pri60lv_Aper5min_20180707-1.zip
- ZIPサイズ：1,362,345,082 bytes
- SHA-256：`40392ecb3b4858bcc4fa4d8db1ec94b46d19688ec9568d35b0aaeb086408b82d`

## アプリ収録範囲

- 日時：2018-07-07 09:00〜10:55 JST（00:00〜01:55 UTC）
- 間隔：5分、24フレーム
- 予測時間：FH0000（各ファイルの基準時刻）のみ
- 範囲：西日本、東経130〜136度・北緯32〜36.333333度
- 数値格子：1920×2080、250m相当を維持したCOG
- 表示画像：1440×1040 WebP
- 値：降水強度 [mm/h]

GRIB2はPDT 4.50011、DRT 5.200で、1つのメッセージ内に40×40の1kmタイルと160×160の250mタイルが繰り返し格納されています。専用DecoderはFH0000の250mタイルだけを選び、座標に基づいて合成します。
